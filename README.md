# Jagadeesh P. — IT Security and Network Engineer Portfolio

A responsive, light-themed static portfolio website built with HTML5, CSS3 and vanilla JavaScript.

## Files
- `index.html` — complete page content and semantic structure
- `styles.css` — responsive layout, styling and CSS illustrations
- `script.js` — mobile navigation and active-section navigation
- `assets/favicon.svg` — JP monogram favicon

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder (keep `index.html` in the repository root).
3. In repository **Settings → Pages**, choose **Deploy from a branch**.
4. Select your deployment branch and `/ (root)`, then save.
5. Open the Pages URL shown by GitHub.

## Notes
- The page uses a Google Fonts stylesheet for DM Sans and Manrope; system sans-serif fallbacks are provided.
- Technology and network visuals are made with local CSS/SVG rather than fragile third-party logo image URLs.
- Contact details are linked with `mailto:`, `tel:`, and the LinkedIn profile.
- The Currently Learning section lists Microsoft Azure Sentinel, Sophos Endpoint Management, Sophos Firewall, Google Workspace, and Zscaler.
- No Wazuh SIEM Practical Lab is included.
- The portfolio presents CCNA/MCSA as knowledge areas and cybersecurity work as learning/practical labs, not certifications or professional SOC experience.
