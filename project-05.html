PROJECT 05 · ASSET INVENTORY AUTOMATION

Laptop Asset Distribution Dashboard

A live inventory dashboard for monitoring prepared laptop availability across office locations and business entities.

Project Overview

Developed a live dashboard using Google Sheets and Google Apps Script to track prepared laptop availability across office locations (Confident Pride and Hustle Hub) and entities (ACKO GI, ACKO Tech and ACKO Life).

Key Features

  • Displays office-wise prepared laptop stock.
  • Provides model-wise and entity-wise inventory breakdown.
  • Includes search and sorting.
  • Automatically hides models with zero stock.
  • Refreshes inventory data every 30 seconds.
  • Automatically initializes the required sheet structure if missing.
